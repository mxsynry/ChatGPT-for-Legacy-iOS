# Stage 15 — iOS 18-inspired UI corrections and backend hardening

## Direct evidence vs interpretation
The binary comparison in `STAGE15-2026-VS-2024-REVIEW.md` was generated by reading both uploaded `ChatGPT.framework` Mach-O binaries. Strings such as `CalpicoMessageActionsSheet`, `SendLongPressModelSelector`, `ConversationDraftLifecycleTracker`, `MessageSourcesView`, and `MessageEditingAttachmentRestorer` exist in the 2026 framework. The *exact gesture behavior, layout, and implementation* cannot be reconstructed from these strings alone. The source here is an original iOS 16 approximation. It is **not** compiled official code.

## Actual Stage 15 changes

| Area | Issue in Stage 14 | Stage 15 implementation |
|---|---|---|
| Message editing | Single-line alert had regressed despite Stage 11 plans | `MessageEditorSheet` uses multiline `TextEditor`, guard before discarding later turns, maintains original photo reference |
| Composer ownership | Large inline block in `RootView` | Independent `ChatComposerView` with image picker, tools menu, dictation, action shortcuts, attachment chips |
| Scrolling | Any SSE delta forcibly scrolled to bottom | Manual scrolling disables auto-follow, visible **Latest** button restores it; no text fade |
| Draft reliability | Debounced save could be canceled by rapid chat switching | Commit previous chat draft synchronously before restoring next draft |
| Web citations | Streaming discarded annotation metadata | `ResponseStreamEvents` parses `response.output_text.annotation.added`, final `response.completed` annotation fallback; `MessageSourcesView` displays tappable source links |
| Citation safety | No link validation | Only HTTP(S), reject credential-bearing URLs, loopback/local callback destinations and oversized URLs; dedupe and cap at 40 citations per message |
| Assistant message migration | No citation field | Optional citations decode to empty list for old conversations |
| Model selection | Header showed raw API model slug | Show catalog display name where available; preserve server-ordered account catalog |
| Navigation | Settings sometimes requested while Chats sheet still open | Dismiss Chats before opening Settings; similarly dismiss Settings before model picker |
| Image uploads | Original-size JPEG could consume 5 MB in JSON history | Resize longest edge to 1536px, cap stored JPEG at 2 MB, cap source data at 40 MB |
| Credential routing | Sending could erase draft/append a message with no selected credentials | Validate explicit plan/API-key route **before** appending user message, leave draft untouched if not ready |
| Automated checks | 62 portable regression checks | 78 portable checks, including terminal stream errors and hostile citation URLs |

## Backend behaviors deliberately not changed
- OAuth still uses the documented open-source `127.0.0.1` callback and `SFSafariViewController`. This path has **not** been verified to survive iOS 16 Safari, Google, or passkey flows on real hardware.
- The source uses **public** `api.openai.com/v1/responses` with `store=false`, `stream=true`; it does not use undocumented private `/backend-api` routes or first-party cookies.
- Official ChatGPT cloud conversations are **not** available through open-source SIWC's granted permission. Offline history import remains supported.
- Stage 15 does not implement first-party locked chats/PIN, live voice, Work, connectors, widgets, or full 2026 UI parity.

## Known remaining risks requiring Xcode / iPhone 8 Plus
1. **Build type-checking:** all SwiftUI, UIKit, SafariServices, Keychain and Network framework APIs must compile with iOS 16 SDK deployment targeting.
2. **Authentication:** OAuth localhost listener may be suspended or unavailable when the browser is in foreground; Google/passkey round-trip remains experimental.
3. **Multiple sheets:** test camera, Chats -> Settings, Settings -> Model Picker, model picker -> return.
4. **Source UX:** real web-search response must contain annotations; verify emitted links open correctly and don't hijack app interactions.
5. **Attachments:** verify image resizing, photo orientation, text-only PDF import, long history performance, and JSON export size.
6. **Streaming:** test rapidly changing chats, Stop, Resume via Regenerate, loss of network, rate-limit errors, delayed tool output.
7. **Drafts:** rapid chat switching (<350 ms), temporary chats and background lock while editing.
8. **Accessibility:** VoiceOver controls, Dynamic Type clipping, landscape, reduced motion, keyboard overlap.
9. **Privacy:** launch/background screenshots and crash/force-quit during active request.

## Build command
On a macOS runner with Xcode + XcodeGen:

```bash
brew install xcodegen
xcodegen generate
xcodebuild -project ChatGPTReconstructed.xcodeproj -scheme ChatGPTReconstructed \
  -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO build
```

The `.github/workflows/ios-build.yml` also compiles and packages an unsigned IPA on the GitHub-hosted macOS runner. No successful Xcode build or iPhone installation is claimed in this package.
